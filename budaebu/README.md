## 자막 3층 → 부대부 적응

기존 거리 인터뷰 포맷의 3층 구조를 토론 포맷으로 옮긴 것입니다.

| 층 | 거리 인터뷰 (기존) | 부대부 (적응) |
|---|---|---|
| **말자막** | 하단 중앙 · 화자별 색 2종 | 하단 중앙 · 화자별 색 **3종** |
| **강조자막** | 하단 중앙 · 흰/노랑/빨강 | 동일 (색 규칙 그대로) |
| **좌상단** | 인물 설명자막 (누적) | **주제 자막 (교체)** ← 성격이 바뀜 |

### 가장 중요한 차이: 좌상단이 누적에서 교체로

거리 인터뷰에서 좌상단 카드는 인터뷰가 진행될수록 줄이 아래로 **쌓였습니다**(8~11줄).
부대부는 쟁점이 ①→②→③으로 넘어가므로 **한 번에 한 쟁점만 떠 있고 통째로 교체**됩니다.

```
[보라 #3F0971 / 흰 글자]  쟁점 ②
[흰 배경 / 검정 글자]     지금은 위험자산인가, 안전자산인가
```

좌표는 기존 인물 카드와 동일하게 두면 됩니다 (@1920×1080 기준):

| 항목 | 값 |
|---|---|
| 카드 좌측 X | 86px (4.5%) |
| 헤더 상단 Y | 294px (27.2%) |
| 헤더 높이 | 78px |
| 헤더→본문 간격 | 15px |
| 본문 줄 높이 | 57px |

단, 패널 소개(오프닝)에서는 **기존 누적 카드 방식 그대로** 인물 프로필을 씁니다
(`패널_설명자막.csv`). 자기소개가 끝나면 제거하고, 본론부터 주제 자막으로 전환합니다.

### 말자막 색 — 3인 확장 (제안)

기존 규칙은 진행자 흰색 / 인터뷰이 노랑 2종이었습니다. 부대부는 화자가 셋이라
색이 하나 더 필요합니다.

| 화자 | 색 | HEX | 근거 |
|---|---|---|---|
| MC | 흰색 | `#FFFFFF` | 기존 진행자 색 그대로 |
| 조규원 (금·원자재) | 노랑 | `#F7EA34` | 기존 게스트 색 유지. 금 = 노랑이라 주제와도 맞음 |
| 강환국 (주식·퀀트) | 시안 | `#35D0F5` | 신규. 노랑의 보색 계열이라 대비 최대 |

빨강 `#F82830`은 강조자막 전용이므로 말자막에 쓰지 않습니다.
공통 스타일(1줄 고정, 검정 외곽선, 글리프 43px @1080p, 하단 여백 102px)은 기존과 동일합니다.

> **확인 필요** — 이미 공개된 부대부 편에서 다른 색을 쓰고 있다면 그쪽을 따라야 합니다.
> 캡처 한 장이면 맞출 수 있습니다.

### 강조자막 — 기존 규칙 그대로

| 색 | HEX | 외곽선 | 쓰임 |
|---|---|---|---|
| 흰색 | `#FFFFFF` | 검정 | 발언 요약·정리 (기본값) |
| 노랑 | `#F7EA34` | 검정 | 금액·배수·연차·수익률·핵심 결론 |
| 빨강 | `#F82830` | **흰색** | 의문·반전 지점 |

토론 포맷이라 **MC의 안건 제시를 빨강 질문으로 띄우고, 두 패널의 상반된 답을
연속으로 받는** 구조가 잘 맞습니다. 기존 사양서의 시그니처 패턴(빨강 질문 → 흰색 답)을
그대로 확장한 것이라, CSV의 각 쟁점 1번 행이 전부 빨강입니다.

**말자막과 강조자막은 같은 자리를 공유하므로 동시에 뜨면 안 됩니다.**
강조자막이 올라오는 2~5초 동안 말자막은 완전히 빼주세요.

## 쓰는 법

1. `좌상단_주제자막.csv`를 먼저 깝니다 — 쟁점 경계만 잡으면 되므로 가장 빠릅니다.
2. `패널_설명자막.csv`로 오프닝 자기소개 구간을 채웁니다.
3. `강조자막_*.csv`의 문구를 순서대로 배치하고, **삽입 지점** 열을 참고해 실제 발화에 맞춥니다.
4. 말자막은 STT 결과에 화자별 색만 입히면 됩니다 (기계화 가능).

문구는 기획안 기준이라 실제 발화와 어순·표현이 다를 수 있습니다.
편집본에서 실제로 나온 말과 다르면 **실제 발화 쪽을 따르세요** — 강조자막은
발화를 그대로 옮기지 않고 명사형으로 재작성하는 층이므로, 뜻만 맞으면 됩니다.

## 아직 못 채운 것

- **실제 타임코드** — SRT나 편집본 타임라인이 있으면 각 문구에 초 단위로 붙일 수 있습니다.
- **말자막 전문** — STT 결과(SRT)를 주시면 화자 분리 + 색 지정 + 6~10자 분할까지 처리합니다.
- **훅 구간(0:00~0:20)** — 본편에서 가장 센 문답을 발췌하는 구간이라, 실제 편집본을 봐야 정합니다.
