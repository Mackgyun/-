# 부대부 자막 → 프리미어 넣는 방법

`00;01;33;21` 형식(세미콜론 = **29.97 드롭프레임**)을 시간 기준으로 변환했습니다.
SRT는 프레임이 아니라 **시간**으로 붙으므로 시퀀스 프레임레이트와 무관하게 같은 지점에 떨어집니다.

## 먼저 알아야 할 제약

Adobe API를 확인한 결과입니다.

> **프리미어의 자막(캡션) 트랙은 스크립트로 제어할 수 없습니다.**
> 캡션 생성·수정·표시 토글 전부 ExtendScript/Automation Blocks에서 접근이 막혀 있습니다.
> 스크립트로 자동 삽입이 되는 건 **MOGRT(모션 그래픽 템플릿)뿐**입니다.

그래서 경로가 둘로 갈립니다.

| | 경로 A — SRT 임포트 | 경로 B — MOGRT + 스크립트 |
|---|---|---|
| 자동화 | 파일 6번 임포트 (수동) | **완전 자동** (79개 한 번에) |
| 스타일 | 트랙 단위 1회 지정 | MOGRT 디자인 그대로 |
| 준비물 | 없음 | **애프터이펙트로 만든 .mogrt 6개** |
| 박스 배경·모션 | 제한적 | 자유 |
| 추천 | 지금 바로 쓸 때 | 회차 반복 제작할 때 |

## 경로 A — SRT 임포트 (준비물 없음)

| 파일 | 트랙 | 큐 | 스타일 |
|---|---|---|---|
| `01_좌상단_주제자막.srt` | 주제 | 7 | 좌상단 · 보라 헤더 박스 |
| `02_설명자막.srt` | 설명 | 10 | `*대상 : 내용` · 작게 |
| `03_상황자막.srt` | 상황·질문 | 19 | 흰색 · 대괄호 반응형 |
| `04_강조자막_빨강.srt` | 강조 R | 15 | `#F82830` · 외곽선 **흰색** |
| `04_강조자막_노랑.srt` | 강조 Y | 19 | `#F7EA34` · 외곽선 검정 |
| `04_강조자막_흰색.srt` | 강조 W | 9 | `#FFFFFF` · 외곽선 검정 |
| `04_강조자막_전체.srt` | (대안) | 43 | 색 구분 없이 한 트랙에 몰 때 |

**색상별로 파일을 나눈 이유** — 프리미어 캡션 스타일은 **트랙 단위**로만 먹습니다.
색이 섞인 한 트랙이면 43개를 하나씩 칠해야 하지만, 3개로 나누면 스타일 3번이면 끝납니다.

순서:

1. **파일 > 가져오기**(Ctrl+I)로 SRT 선택 → 프로젝트 패널에 캡션 항목 생성
2. 타임라인으로 드래그. 파일마다 **별도 캡션 트랙**(C1, C2, C3…)으로 올립니다.
3. **창 > 텍스트 > 캡션**에서 캡션 하나를 스타일링한 뒤
   **모두에 적용** 또는 **트랙 스타일 저장** → 트랙 전체 일괄 적용
4. 좌상단 주제 자막처럼 **박스 배경이 필요한 트랙**은
   **그래픽 및 제목 > 캡션을 그래픽으로 업그레이드**
   → 텍스트 레이어로 바뀌어 배경 박스·정렬을 직접 만질 수 있습니다.
   되돌릴 수 없으니 **시퀀스를 복제한 뒤** 하세요.

## 경로 B — MOGRT + 스크립트 (완전 자동)

`부대부_자막삽입.jsx` — 79개 자막을 타임코드에 맞춰 한 번에 꽂습니다.

### 준비

**애프터이펙트에서** 스타일별 MOGRT 6개를 만듭니다
(주제 / 설명 / 상황 / 강조 빨강 / 강조 노랑 / 강조 흰색).

> ⚠️ **프리미어에서 만든 mogrt는 안 됩니다.** 스크립트로 파라미터를 읽으면 null이 나옵니다.
> AE의 **에센셜 그래픽** 패널에서 텍스트 레이어의 소스 텍스트를 노출시킨 뒤 mogrt로 내보내세요.

노출시킨 텍스트 파라미터 이름을 스크립트의 `TEXT_PARAM`과 맞춥니다(기본값 `"본문"`).

### 실행

1. `.jsx` 상단 **설정 블록만** 고칩니다 — MOGRT 6개 경로, 트랙 번호, 파라미터 이름
2. 프리미어에서 대상 시퀀스를 **활성화**
3. **파일 > 스크립트 > 스크립트 파일 실행** → `부대부_자막삽입.jsx`
4. 끝나면 `삽입 79 / 전체 79` 알림. 실패가 있으면 **바탕화면에 로그**를 남깁니다

### 스크립트가 하는 일

```javascript
seq.importMGT(path, 시작초, 트랙, 0)        // 타임코드 지점에 MOGRT 삽입
clip.getMGTComponent()
    .properties.getParamForDisplayName("본문")
var p = JSON.parse(param.getValue())
p.textEditValue     = "자막 문구"
p.fontTextRunLength = [문구.length]        // ← 길이가 안 맞으면 글자가 깨집니다
param.setValue(JSON.stringify(p), true)
clip.end = 종료시각                         // 큐 길이에 맞춰 트림
```

되돌리려면 실행 직후 Ctrl+Z가 아니라 **해당 트랙을 통째로 선택해 삭제**하는 게 확실합니다.
처음엔 `CUES` 배열을 5~6개만 남기고 시험해 보세요.

## 색 배정 기준

주신 원칙 그대로입니다. `강조자막_색상표.csv`에서 확인·수정하실 수 있습니다.

- **빨강** — 과열, 급락, 불신, 금리 우려, 레버리지 위험 (15개)
- **노랑** — 저평가, 실적, 상승 동력, AI 수요, 주주환원 (19개)
- **흰색** — 질문, 정의, 중립적인 설명 (9개)

바꾸실 항목만 알려주시면 SRT와 jsx를 다시 뽑겠습니다.

## 확인 필요한 2가지

1. **마지막 주제 자막 끝 TC** — 원문이 `00;39;13;28 - 영상 종료`라 끝점이 없어
   임시로 `00;41;00;00`을 넣었습니다(알려진 마지막 자막이 `00;40;52;13`). 실제 길이를 주시면 맞추겠습니다.
2. **`[하나만 고르라는 질문이 제일 어려움]`** (`00;35;58;21`) — 4·5 목록에 있어 강조자막 흰색에 넣었지만,
   대괄호 형식이라 성격은 상황자막(3번)에 가깝습니다. 옮길지 알려주세요.

## 안 건드린 것

`1.txt`(말자막 기준본)는 그대로 뒀습니다. SRT가 필요하시면 원본을 주시면 변환하겠습니다.
