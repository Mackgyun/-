# 모션그래픽 클립 워크플로우

대본 문장 → 짧은 무음 클립. 자막은 나중에 편집 앱(CapCut 등)에서 따로 올리고,
이 클립은 그 **뒤에 깔리는 배경 영상**이다.

렌더 방식은 생성형이 아니다. HTML 페이지를 크롬이 프레임 단위로 캡처해 이어붙인다.
따라서 결과는 결정적(deterministic)이고, 픽셀 단위로 수정 가능하다.

## 0. 전제

- Node.js 22 이상, ffmpeg 설치 필요 (`npx hyperframes doctor`로 확인, 전 항목 ok)
- HyperFrames 코어 스킬이 설치돼 있어야 한다: `npx hyperframes skills update`
- 폰트: GMarket Sans (`GmarketSansBold.ttf`, `GmarketSansMedium.ttf`).
  공식 배포처 corp.gmarket.com/fonts 에서 받아 클립 폴더의 `assets/`에 둔다.
- 버전은 `@latest`로 통일한다. CLI만 옛 버전에 핀하면 설치된 스킬 문서(최신)와 어긋난다.

작성 규칙의 근거가 되는 원본 계약은 `/hyperframes-core`에 있다. 컴포지션 HTML을
쓰기 전에 그쪽을 먼저 읽는다. 이 스킬은 그 위에 얹는 프로젝트 고유 규칙이다.

## 1. 대본을 클립 계획표로

문장 단위로 자르고 문장마다 길이와 캔버스를 배정한다.

- SRT가 있으면 그 타이밍을 그대로 쓴다.
- 없으면 문장당 2~3초.
- 눈길을 끄는 문장, 도구/브랜드 이름이 나오는 문장 → `full`
- 부연 설명 문장 → `square`

| 캔버스 | 픽셀 | 용도 |
| --- | --- | --- |
| `full` | 1080x1920 | 세로 풀화면. 강조 문장 |
| `square` | 1080x1080 | 화면 중앙 삽입. 부연 설명 |
| `half` | 1080x960 | 상/하단 절반 삽입 |

출력은 번호 · 문장 · 길이 · 캔버스 · 워시 · 컨셉 6열 표.

## 2. 자막 중복 금지 — 최우선 규칙

자막은 편집 앱에서 따로 올린다. 클립에도 같은 문장이 있으면 화면에 같은 말이 두 번 나온다.

1. 대본 문장을 클립에 **그대로 쓰지 않는다.** 문장 속 단어를 라벨로 복사하는 것도 금지.
2. 클립은 기본적으로 **글자 없이** 만든다. 넣더라도 **자막에 없는 새 단어 1~3개**만
   (판정 단어, 브랜드명, 숫자, 단위).
3. 문장을 통째로 박는 건 "이 클립엔 자막을 안 올린다"는 뜻일 때만. 의도적으로만 한다.

변환 예시:

| 자막 문장 | 클립 화면 |
| --- | --- |
| 이 글은 AI가 쓴 글입니다 | 스캔 카드 + `HUMAN?` |
| 한 달 만에 결과가 나왔어요 | 넘어가는 달력 + `30` |
| 이 도구는 무료입니다 | 가격표 + `FREE` 뱃지 |

검수법: 클립 속 글자를 소리 내 읽는다. 자막에 있는 단어면 반려하고 다시 만든다.

## 3. 디자인 토큰

밝은 회백 배경 위에 큰 파스텔 블롭이 흐리게 떠다니고, 그 위에 반투명 흰 카드가 뜬다.

| 항목 | 값 |
| --- | --- |
| 배경 | `#f8f9fa` |
| 카드 | `rgba(255,255,255,0.7)`, `border-radius: 40px` |
| 히어로 텍스트 | 120~170px / Bold / `#0f172a` |
| 보조 텍스트 | 40~52px / Medium / `#475569` |
| 글꼴 | GMarket Sans 전용 |

워시(블롭 색 조합)는 `references/washes.md`의 6종에서 고른다.
**이웃한 클립은 반드시 다른 워시**를 쓴다. 0↔1이 대비가 가장 크다.

## 4. 움직임 규칙

- 등장: 아래에서 올라오며 페이드인, 0.5초 안팎. 카드는 `back.out(1.6)`으로 살짝 튀게.
- 상시: 배경 블롭이 숨 쉬듯 느리게 부유.
- 강조: 게이지 차오름, 뱃지 팝, 숫자 카운트업 정도.
- 금지: 무한 반복 애니메이션, 글리치 남발, `Math.random()`.

**다양성**: 이웃 클립에 같은 구도를 쓰지 않는다. 한 영상 안에 최소 4가지 구도를
섞는다 — 카드형 / 숫자 카운터 / 게이지 / 아이콘 배치 / 스탬프 판정 / 타임라인.

## 5. 클립 작성 규칙

클립 하나 = 폴더 하나.

```
clip-01/
  index.html
  assets/
    GmarketSansBold.ttf
    GmarketSansMedium.ttf
```

컴포지션 HTML을 쓸 때 지킬 것:

1. `html`/`body`를 캔버스 픽셀 크기로 고정하고, 루트 div에
   `data-composition-id`, `data-width`, `data-height`, `data-duration`을 넣는다.
2. GSAP 타임라인은 `gsap.timeline({ paused: true })`로 **정확히 1개**만 만들고
   `window.__timelines["<data-composition-id와 동일한 값>"]`에 등록한다.
   등록을 빠뜨리면 클립이 움직이지 않는다.
3. 폰트는 `@font-face`로 `assets/` 상대경로 선언. 모든 경로는 상대경로.
4. 배경색은 루트가 아니라 `position: absolute; inset: 0`인 **자식 div**에 칠한다.
   루트에 직접 칠하면 영상이 통째로 검게 나온다.
5. **애니메이션 최종 상태를 `data-duration`보다 살짝 앞에서 끝낸다.**
   표시 구간이 반개구간 `[start, start + duration)`이라 정확히 duration 시점의
   프레임은 렌더되지 않는다. 2.9초 클립이면 최종 포즈를 2.8초쯤에 안착시킨다.
6. `data-track-index`는 Studio 타임라인 표시용일 뿐 렌더가 읽지 않는다.
   쌓임 순서는 DOM 순서와 CSS로 만든다.
7. GSAP은 버전을 핀한 CDN으로: `https://cdn.jsdelivr.net/npm/gsap@3.14.2/dist/gsap.min.js`

뼈대는 `references/skeleton.html` 참고.

## 6. 검증과 렌더

클립 폴더 안에서:

```bash
# 편집 중 빠른 정적 피드백
npx hyperframes lint

# 최종 게이트 — lint를 포함하므로 앞에 lint를 또 붙이지 않는다
npx hyperframes check --snapshots

# 굽기
npx hyperframes render --quality high --output clip-01.mp4
```

`check`는 브라우저를 띄워 런타임 에러, **로드 실패한 리소스**(폰트가 □로 나오는 원인),
**레이아웃 넘침**(화면 밖 잘림), 대비, 모션까지 한 번에 잡는다. `lint`만 돌리고
넘어가지 않는다.

반복 중에는 `--quality draft`로 빠르게, 확정되면 `high`로 다시 굽는다.

**투명 배경 클립**(인물 영상 위에 얹을 때): 배경 레이어를 아예 빼고
`--format webm`으로 렌더한다. CapCut이 webm 알파를 그대로 인식한다.

## 7. 업로드 전 육안 체크

`check`가 통과한 뒤에도 사람이 볼 것 — 자동화가 판단할 수 없는 항목들이다.

1. 소리와 자막 없이 클립만 봐도 문장의 분위기가 전달되는가?
   (단어 하나 띄운 빈 카드는 탈락)
2. 클립 속 글자가 자막 문장의 복사본은 아닌가? (2장)
3. 바로 앞 클립과 색·구도가 똑같지 않은가?

**예외**: 화면 조작을 설명하는 문장("여기를 누르고, 이 메뉴에 들어가서…")은
모션그래픽보다 실제 화면 녹화가 훨씬 설득력 있다. 클립을 만들지 말고 녹화로 대체한다.

## 8. 수정

- 새 이름으로 렌더한다: `--output clip-01_v2.mp4`. 덮어쓰면 비교할 수 없다.
- 부분 수정은 콕 집어서: "clip-03 카드를 Peach 워시로", "히어로 글자 더 크게".
- 느낌을 갈아엎을 땐 컨셉부터: "같은 문장으로 전혀 다른 구도 2개 시안 —
  하나는 게이지, 하나는 스탬프 판정으로."

## 트러블슈팅

| 증상 | 원인 |
| --- | --- |
| 글자가 전부 □ | 폰트 파일이 `assets/`에 없거나 `@font-face` 경로 오타. `check`가 잡는다 |
| 영상이 전부 검정 | 배경을 루트에 직접 칠함 → 5장 4번 |
| 클립이 안 움직임 | `window.__timelines` 등록 누락 → 5장 2번 |
| 마지막 포즈가 안 보임 | 최종 상태를 duration에 정확히 맞춤 → 5장 5번 |
| 투명 webm 미리보기가 검정 | 플레이어가 알파를 못 그리는 것. 편집 앱 타임라인에서 확인 |
| 클립들이 다 비슷함 | 컨셉과 워시 번호를 매번 다르게 지정 → 3·4장 |
