# 촬영원본 폴더 → 구글 시트 자동 동기화

NAS(`\\192.168.0.45\10tb\촬영원본`)의 폴더를 주기적으로 훑어서
**"어떤 콘텐츠의 몇 편이 실제로 촬영/입고되었는지"** 를 구글 시트에 자동으로 채워 넣습니다.
편수 확인을 사람이 눈으로 대조하지 않아도 되게 만드는 것이 목적입니다.

---

## 왜 이 방식인가

| 방식 | 가능 여부 | 이유 |
|---|---|---|
| 구글 Apps Script만으로 처리 | ❌ | 구글 서버는 사내 NAS(192.168.0.45)에 접근할 수 없음 |
| 원본을 구글 드라이브에 동기화 | △ | 용량(10TB)·업로드 시간 때문에 비현실적 |
| **사내 PC에서 폴더 스캔 → 시트 API 기록** | ✅ | 원본은 NAS에 그대로 두고 "목록 정보"만 전송 |

그래서 이 스크립트는 **NAS에 접근 가능한 사내 PC(또는 상시 켜져 있는 편집실 PC)** 에서 돌아갑니다.
전송되는 건 폴더명·파일 개수·용량·수정일뿐이고, 영상 파일 자체는 절대 업로드하지 않습니다.

---

## 무엇이 시트에 채워지나

기존 표(A: 카테고리, B: 제목, C: 담당자, D: 완성일정, E: 비고)는 **건드리지 않고**,
그 오른쪽에 상태 열을 추가로 관리합니다.

| 열 | 이름 | 내용 |
|---|---|---|
| F | 원본상태 | `원본 있음` / `원본 없음` |
| G | 파일수 | 해당 편 폴더의 영상 파일 개수 |
| H | 용량(GB) | 원본 총 용량 |
| I | 촬영일(파일기준) | 파일 최종 수정일 |
| J | 원본폴더 | NAS 상대 경로 |
| K | 확인시각 | 마지막 점검 시각 |

추가로 **`미매칭폴더` 탭**이 자동 생성되어, NAS에는 있는데 시트에는 없는 폴더를 모아 보여줍니다.
→ "촬영은 했는데 시트에 안 적힌 편"이 여기서 바로 드러납니다.

---

## 인식하는 폴더 구조

셋 다 자동으로 인식합니다. 지금 쓰는 방식을 바꿀 필요 없습니다.

```
촬영원본/
├─ 고앙이앙고싶다 시즌6 해장엽/        ← A) 제목 폴더 + 편수 하위 폴더
│  ├─ 1편/  C0001.MP4 ...
│  └─ 2편/  C0007.MP4 ...
├─ 고앙이앙고싶다 시즌6 딥톡 유방엽 EP.3/   ← B) 제목에 편수 포함
│  └─ C0012.MP4 ...
└─ 보이는라디오/                      ← C) 프로그램 폴더 한 단계 더
   └─ 0629_의진짐(성복우리아이들병원 소아청소년과)/
      └─ 2편/  C0020.MP4 ...
```

편수 표기는 `EP.1`, `EP 01`, `1편`, `제2편`, `3화`, `_4`, `_2(강영)` 를 모두 읽습니다.
`시즌6` 의 숫자는 편수로 오인하지 않습니다.

제목은 정확히 같지 않아도 됩니다. 말머리(`[흉]`, `[수]`), 날짜 프리픽스(`0629_`),
괄호 주석(`(성복우리아이들병원 소아청소년과)`), 공백·언더바 차이는 무시하고 유사도로 매칭합니다.

## 설치 (최초 1회)

### 1단계 — 구글 서비스 계정 만들기

1. https://console.cloud.google.com 접속 → 프로젝트 생성 (예: `촬영관리`)
2. **API 및 서비스 → 라이브러리** → `Google Sheets API` 검색 → **사용 설정**
3. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → 서비스 계정**
   - 이름: `sheet-sync` → 만들기 → 역할은 지정하지 않고 완료
4. 만들어진 서비스 계정 클릭 → **키 → 키 추가 → 새 키 만들기 → JSON**
   → 다운로드된 파일을 이 폴더에 **`service_account.json`** 이름으로 저장
5. JSON 파일 안의 `client_email` 값(예: `sheet-sync@촬영관리.iam.gserviceaccount.com`)을 복사해서,
   **구글 시트에서 그 주소를 편집자로 공유**합니다. ← 이걸 빠뜨리면 권한 오류가 납니다.

### 2단계 — PC 준비

```bat
:: 파이썬 3.10 이상 설치 후 (https://www.python.org/downloads/ , "Add to PATH" 체크)
cd /d C:\촬영자동화\automation
pip install -r requirements.txt
```

### 3단계 — 설정 파일 작성

`config.example.json` 을 `config.json` 으로 복사한 뒤 아래 두 가지만 확인하면 됩니다.

```jsonc
{
  "root_path": "\\\\192.168.0.45\\10tb\\촬영원본",   // 역슬래시는 두 번씩
  "google": {
    "spreadsheet_id": "1AbC...",   // 시트 URL의 /d/ 와 /edit 사이 문자열
    "sheet_name": "시트1",          // 탭 이름 (화면 아래쪽 탭에 적힌 그대로)
    "columns": { ... }             // 표 구조가 다르면 여기서 열 문자만 바꾸면 됩니다
  }
}
```

### 4단계 — 단계별로 확인

```bat
:: (1) 폴더 인식이 맞는지부터 — 구글 연결 없이 실행됩니다
python sync_footage_to_sheet.py --scan-only

:: (2) 시트와 어떻게 매칭되는지 미리보기 — 시트에 아무것도 쓰지 않습니다
python sync_footage_to_sheet.py --dry-run

:: (3) 상태 열 머리글 넣고 실제 반영
python sync_footage_to_sheet.py --init-headers
```

`--dry-run` 에서 엉뚱하게 붙은 편이 있으면 `config.json` 의
`matching.min_score` 를 `0.8` 정도로 올리고,
반대로 붙어야 할 게 안 붙으면 `0.65` 로 낮춰서 다시 확인하세요.
표기가 아예 다른 경우는 `matching.aliases` 에 `{"잘못된표기": "시트표기"}` 로 넣으면 됩니다.

### 5단계 — 자동 실행 등록

관리자 PowerShell에서:

```powershell
powershell -ExecutionPolicy Bypass -File register_task.ps1 -IntervalMinutes 15
```

15분마다 자동으로 돌면서 시트를 갱신합니다. 실행 기록은 `logs\sync_YYYYMMDD.log` 에 쌓입니다.

즉시 한 번 돌려보기: `Start-ScheduledTask -TaskName "촬영원본-구글시트-동기화"`

## 운영 팁

- **폴더명이 곧 시트 제목입니다.** 촬영 담당자가 폴더를 만들 때 시트 제목을 복사해 붙이면
  매칭률이 100%에 가까워집니다. 최소한 `제목 + 편수`만 지키면 됩니다.
- **`미매칭폴더` 탭을 주간 회의 때 확인**하세요. 여기가 비어 있으면 NAS와 시트가 일치한다는 뜻입니다.
- 스크립트는 **값이 실제로 바뀐 행만** 시트에 씁니다. 15분마다 돌아도 시트 수정 기록이 지저분해지지 않습니다.
- 사람이 채우는 열(담당자·완성일정·비고)은 스크립트가 절대 덮어쓰지 않습니다.

## 문제 해결

| 증상 | 해결 |
|---|---|
| `촬영원본 경로에 접근할 수 없습니다` | 탐색기에서 `\\192.168.0.45\10tb` 가 열리는지 확인. 로그인이 필요하면 `run_sync.bat` 의 `net use` 줄 주석을 해제하고 계정 입력 |
| `403` / `The caller does not have permission` | 서비스 계정 이메일을 시트에 **편집자**로 공유했는지 확인 |
| `Unable to parse range` | `sheet_name` 이 실제 탭 이름과 다름 |
| 폴더를 하나도 못 찾음 | `config.json` 의 `video_extensions` 에 실제 촬영 확장자가 있는지, `min_file_size_mb`(기본 50MB)가 너무 큰지 확인 |
| 로그 한글이 깨짐 | `run_sync.bat` 의 `chcp 65001` 이 살아 있는지 확인 |
| 편수가 잘못 읽힘 | `--scan-only` 로 어떻게 읽었는지 확인 후 폴더명 수정 (권장) 또는 `EP_PATTERNS` 조정 |

## 파일 구성

```
automation/
├─ sync_footage_to_sheet.py   메인 스크립트
├─ config.example.json        설정 템플릿 → config.json 으로 복사해 사용
├─ requirements.txt           파이썬 의존성
├─ run_sync.bat               작업 스케줄러가 실행하는 배치 파일
├─ register_task.ps1          작업 스케줄러 자동 등록
└─ README.md                  이 문서
```

> `config.json` 과 `service_account.json` 은 계정 정보가 들어 있으므로 깃에 올라가지 않습니다(.gitignore 처리).
