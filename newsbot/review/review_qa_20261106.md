# 동작 점검 보고서 (2026-11-06)

코드를 쓰지 않은 별도 검토 에이전트가 앱 전체를 실제로 돌려 보고 찾은 문제와, 이후 고친 결과입니다.

## 점검 방법
- 자동 테스트 40개 실행
- API: 새 DB에서 초대 가입, 권한, 담당 충돌, 페이지 넘김, 개수 일치, 한도, 로그인 잠금을 직접 호출
- 수집·알림: DART 500·503·020 응답과 수집 도중 실패를 가짜 응답으로 재현
- 메일: 최소 IMAP 서버에 실제 imaplib로 접속, 중단 뒤 새 메일 120통 상황 재현
- 화면: Playwright로 PC(1440×900)와 iPhone 13, 라이트·다크 모드
- Windows 스크립트, README, 이전 검토(`review_independent.md`)와 코드 대조

실제 DART·알리오·AI 키 없이 점검했으므로 외부 연결은 가짜 응답으로만 확인했습니다.

## 함께 추가한 운영 기능
- 매일 새벽 4시 자동 백업(`data/backups`, 최근 14개), `python -m newsbot backup` 명령
- 로그 파일 `data/logs/newsbot.log`(5MB × 5개 순환, 인증키 가림)
- `python -m newsbot reset-password 아이디`
- `/healthz`가 DART·알리오 수집과 정기 브리핑 중단을 503으로 알림
- `setup.ps1`이 `py` 런처가 없는 Python에서도 동작
- 무료 AI 시험: Gemini 무료 등급(`LLM_PROVIDER=gemini`), 로컬 Ollama(`LLM_PROVIDER=ollama`)

## 남은 것 (확인 못 했거나 다음 단계)
- 실제 DART·알리오·Claude·OpenAI·Gemini 호출은 키가 없어 확인하지 못했습니다. Gemini 무료 등급의 OpenAI 호환 주소와 모델 이름은 Google 공식 문서(2026-11)로 확인했습니다.
- Windows 작업 스케줄러: Microsoft 계정·PIN으로만 로그인하는 노트북은 등록할 때 비밀번호 입력이 막힐 수 있습니다. 첫 설치 때 확인이 필요합니다.
- 이전 검토 중 미반영: corp_code 기준 감시 목록, 회사명 NFKC 정규화, DPAPI로 암호화 키 보호, 사용자 삭제·데이터 보존 기간, 관리자 감사 로그, 설정 화면에서 감시 목록 편집.
