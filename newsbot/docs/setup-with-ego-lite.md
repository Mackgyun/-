# API 발급과 서버 설정: 에고라이트로 맡기기

[Ego Lite(에고라이트)](https://dev.to/terminalchai/ego-lite-the-open-source-browser-built-for-humans-and-ai-agents-3cp)는 Claude Code나 Codex 같은 AI 에이전트가 사람 옆에서 웹을 대신 조작하는 브라우저입니다. 이 문서는 회원가입, 키 신청, 설정 화면 이동처럼 반복적인 웹 작업을 에이전트에게 맡기는 순서와 그대로 붙여 넣을 지시문을 정리한 것입니다.

## 먼저 정해 둘 규칙

에이전트에게 맡기되, 아래는 **사람이 직접** 합니다. 지시문에도 같은 내용을 넣어 두었습니다.

| 사람이 할 일 | 이유 |
| --- | --- |
| 로그인, 휴대폰·공동인증서 본인인증, 2단계 인증 | 계정 보안 |
| 약관 동의, 결제 수단 등록, 결제 | 법적 책임과 비용 |
| 발급된 키를 서버 PC의 `.env`에 붙여 넣기 | 키가 대화 기록에 남지 않게 |

- 키는 채팅창, 메신저, 메모 앱에 붙이지 않습니다. 화면에 키가 보이면 에이전트는 그 자리에서 멈추고, 사람이 복사해 `.env`에 바로 넣습니다.
- 에고라이트는 현재 macOS에서 쓰는 사람이 많습니다. 웹 작업은 개인 맥에서 하고, 키만 서버 PC의 `.env`에 넣으면 됩니다. 서버 PC가 Windows여도 상관없습니다.
- 회사 명의 계정(공용 메일)으로 가입해야 담당자가 바뀌어도 키를 관리할 수 있습니다.

## 순서

| 순서 | 작업 | 필수 | 비용 | 걸리는 시간 |
| --- | --- | --- | --- | --- |
| 1 | OpenDART 인증키 | 필수 | 무료 | 10분 |
| 2 | AI 키 (시험: Gemini 무료 / 실사용: Anthropic) | AI 기능을 쓸 때 | 무료 / 사용량 과금 | 10~20분 |
| 3 | 공공데이터포털 계정과 식약처 API 활용신청 | 다음 단계 기능(식약처 수집)용 | 무료 | 15분 |
| 4 | 열린국회정보 인증키 | 다음 단계 기능(법안 추적)용 | 무료 | 10분 |
| 5 | UptimeRobot 감시 등록 | 권장 | 무료 | 5분 |

3·4번은 아직 앱에 수집 기능이 없지만, 키 발급에 며칠 걸리는 경우가 있어 미리 받아 두면 좋습니다.

## 1. OpenDART 인증키

에고라이트에 붙여 넣을 지시문:

```text
OpenDART(https://opendart.fss.or.kr)에서 회사용 인증키를 신청하려고 해.
1) 첫 화면에서 '인증키 신청·관리' 메뉴를 찾아 '인증키 신청' 화면까지 이동해 줘.
2) 신청 양식에서 사용 용도는 "언론사 사내 공시 모니터링(보도 목적)"으로 적어 줘. 이메일, 이름, 휴대폰 같은 개인정보 칸은 비워 두고 나에게 넘겨.
3) 약관 동의, 본인인증, 최종 '신청' 버튼은 누르지 말고 그 화면에서 멈춰.
4) 인증키가 화면에 보이면 키를 읽거나 적지 말고 "키가 보입니다"라고만 말하고 멈춰.
```

받은 키는 서버 PC의 `.env`에 넣습니다.

```bash
notepad .env
```

`DART_API_KEY=` 뒤에 붙여 넣고 저장한 다음 프로그램을 다시 시작합니다.

## 2. AI 키

### 시험용: Gemini 무료 등급

```text
Google AI Studio(https://aistudio.google.com/apikey)에서 API 키를 만들려고 해.
1) 로그인이 필요하면 멈추고 나에게 넘겨.
2) 'API 키 만들기(Create API key)' 화면까지 이동해 줘. 새 프로젝트를 만들어야 하면 이름은 "chungnyun-briefing-test"로 해.
3) 결제(Billing) 설정 화면이 나오면 아무것도 바꾸지 말고 멈춰. 무료 등급으로만 쓸 거야.
4) 키가 화면에 보이면 읽거나 적지 말고 멈춰.
```

`.env`에는 `LLM_PROVIDER=gemini`, `GEMINI_API_KEY=발급한키`를 넣습니다. 무료 등급은 입력 내용이 Google 제품 개선에 쓰일 수 있으므로 공개 공시 같은 자료로만 시험합니다.

### 실사용: Anthropic (Claude)

```text
Anthropic Console(https://console.anthropic.com)에서 회사용 API 키를 만들려고 해.
1) 로그인·가입·본인인증이 필요하면 멈추고 나에게 넘겨.
2) 조직(Organization) 이름이 비어 있으면 "청년의사"로 적되, 저장 버튼은 누르지 말고 나에게 확인받아.
3) 결제(Billing) 화면으로 이동만 하고, 카드 등록이나 충전은 하지 마.
4) 사용 한도(Limits) 화면을 찾아서 월 사용 한도를 설정하는 곳을 보여 줘. 금액은 내가 넣을게.
5) API Keys 화면에서 'Create Key'를 누르기 직전에 멈춰. 키 이름은 "briefing-server"로 할 거야.
6) 키가 화면에 보이면 읽거나 적지 말고 멈춰.
```

`.env`에는 `LLM_PROVIDER=claude`, `ANTHROPIC_API_KEY=발급한키`를 넣습니다. 콘솔의 월 사용 한도와 앱의 기자별 월 한도(관리자 화면)를 함께 걸어 두면 비용이 두 겹으로 막힙니다.

## 3. 공공데이터포털 식약처 API (다음 단계용)

```text
공공데이터포털(https://www.data.go.kr)에서 아래 오픈 API의 '활용신청' 화면까지 차례로 이동해 줘.
로그인이 필요하면 멈추고 나에게 넘겨.
- 식품의약품안전처_의약품 회수·판매중지 정보 (데이터 ID 15059114)
- 식품의약품안전처_의약품 안전성 서한 (15059182)
- 식품의약품안전처_의약품 행정처분 정보 (15058457)
- 식품의약품안전처_의약품 생산·수입·공급 중단 보고 (15057899)
- 식품의약품안전처_임상시험 정보 (15056835)
- 식품의약품안전처_의약품 제품 허가정보 (15095677)
각 화면에서 활용 목적은 "언론사 사내 보도용 모니터링"으로 적고, 최종 '활용신청' 버튼은 내가 누를게. 각 API마다 멈춰서 알려 줘.
```

데이터 ID와 서비스 이름은 2026년 11월 조사 기준입니다. 공공데이터포털은 버전이 바뀌면 이름 뒤 숫자가 달라질 수 있으니, 화면의 이름이 조금 다르면 에이전트가 비슷한 이름을 찾아 보여 주게 하면 됩니다. 일반 인증키(ServiceKey) 하나로 여러 API를 함께 씁니다.

## 4. 열린국회정보 인증키 (다음 단계용)

```text
열린국회정보(https://open.assembly.go.kr)에서 Open API 인증키를 신청하려고 해.
1) 로그인이 필요하면 멈추고 나에게 넘겨.
2) '인증키 신청' 화면까지 이동하고, 활용 목적은 "언론사 보건복지위원회 법안 모니터링"으로 적어 줘.
3) 최종 신청 버튼은 누르지 말고 멈춰.
```

## 5. UptimeRobot 감시 등록

서버에 HTTPS 주소(보안 터널)를 붙인 뒤에 합니다.

```text
UptimeRobot(https://uptimerobot.com)에서 무료 모니터를 하나 만들어 줘.
1) 로그인·가입이 필요하면 멈추고 나에게 넘겨.
2) 'New Monitor'에서 종류는 HTTP(s), 주소는 https://<우리 도메인>/healthz, 확인 주기는 5분으로 채워 줘.
3) 알림 받을 연락처는 내가 고를 테니 그 칸에서 멈춰.
```

`/healthz`는 DART·알리오 수집이나 정기 브리핑이 멈추면 503을 돌려주므로, 서버가 꺼졌을 때뿐 아니라 수집이 멈췄을 때도 메일이 옵니다.

## 실제로 해 본 기록 (2026-11-24, Windows)

Windows 노트북의 Claude Code에서 에고라이트(`ego-browser` v2.2.1)로 1·2번을 실행해 본 결과입니다. 화면 구성은 그날 기준이라 바뀔 수 있습니다.

- **Windows에서도 동작합니다.** PowerShell에서는 지시문을 UTF-8 `.mjs` 파일로 저장한 뒤 `ego-browser nodejs -e "await import('file:///C:/.../round-01.mjs')"`로 실행합니다(한글을 `-e`에 직접 넣으면 깨짐). 탭 하나에 사이트 하나씩, 세 사이트를 한 작업 공간에서 차례로 열었습니다.
- **에이전트가 키를 보지 않게:** 화면 글자를 읽을 때 `sk-ant-…`, `AIza…` 같은 키 형태 문자열은 스크립트 안에서 `[KEY]`로 가린 뒤 출력하고, 키 형태가 보이면 출력하지 않고 멈추게 했습니다.

| 사이트 | 에이전트가 멈춘 곳 | 사람이 한 일 / 할 일 |
| --- | --- | --- |
| OpenDART | '인증키 신청/관리' → 로그인 화면 → '인증키 신청' 버튼 → **오픈API 이용약관 동의** 화면. 비회원 신청은 약관 동의가 첫 단계라 양식 입력 전에 멈춤 | 약관 동의 → 개인용/기업용 선택 → 양식 입력 → 신청 |
| Google AI Studio | 브라우저에 이미 로그인돼 있어 바로 **API 키 목록** 화면. 'API 키 만들기' 앞에서 멈춤 | 'API 키 만들기'. 개인 계정에 기존 키가 있으면 회사 계정으로 새로 만드는 것을 권장 |
| Anthropic Console | `console.anthropic.com/settings/keys`가 **`platform.claude.com` 로그인 화면**으로 넘어감 → 사람이 로그인 → **API 키 화면 '키 생성' 앞**에서 멈춤 | '키 생성'(이름 `briefing-server`). 무료 '평가 액세스' 플랜이면 상업적 사용 전에 결제 설정 필요. Limits에서 월 한도 설정 |

- Anthropic 로그인 버튼 아래에 "계속 진행하면 약관에 동의한 것으로 간주"한다는 문구가 있어, 로그인 자체가 약관 동의를 겸합니다. 그래서 로그인은 사람이 합니다.
- 쿠키 동의 배너(Google, Anthropic)는 에이전트가 건드리지 않고 사람이 고르게 두었습니다.
- 사람에게 넘길 때는 작업 공간을 `handOff()`로 넘기고, 사람이 "로그인 완료"라고 하면 같은 작업 공간을 `takeOverTaskSpace()`로 다시 받아 이어 갔습니다. 새 작업 공간을 만들 필요가 없습니다.

## 서버 PC 안의 설치는 에고라이트가 아니라 터미널에서

Python 설치, `setup.ps1`, 자동 시작 등록은 웹 작업이 아니라 서버 PC의 명령 실행입니다. 서버 PC에 Claude Code를 설치했다면 README의 '노트북(Windows)에 설치하기' 순서를 그대로 맡길 수 있습니다. 이때도 `.env`의 키 입력과 관리자 권한 승인은 사람이 합니다.
