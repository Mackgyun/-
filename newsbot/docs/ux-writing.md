# 문구 원칙 (v1, 2026-11)

목표는 **전문적이고 직관적인** 문구입니다. 이전 문구는 친근한 해요체에 덧말이 많아 'AI가 쓴 글' 느낌이 났습니다.

## 참고한 가이드
- [토스 라이팅 8원칙](https://velog.io/@jbee/%ED%86%A0%EC%8A%A4%EC%9D%98-8%EA%B0%80%EC%A7%80-%EB%9D%BC%EC%9D%B4%ED%8C%85-%EC%9B%90%EC%B9%99%EB%93%A4): 예측 가능한 힌트, 잡초 뽑기, 빈 문장 제거, 핵심 메시지, 말하기 쉬운 문장, 강요 대신 제안, 누구나 아는 말, 숨은 감정
- [Microsoft 스타일 가이드 10가지](https://learn.microsoft.com/en-us/style-guide/top-10-tips-style-voice): 적은 단어, 핵심 먼저, 짧게, 약한 표현('할 수 있습니다', '있습니다') 줄이기
- 한국어 'AI 티' 유형([yoonmoon](https://github.com/amondnet/yoonmoon)): 번역투, 피동 남용, 상투어, 접속사 남발, 기계적 병렬, 명사화, 과잉 수식, 시각 장식(이모지·줄표), 단조로운 리듬

## 규칙
1. **문장은 합니다체.** 상태·안내·오류·완료 문장은 '~합니다/~했습니다'로 끝냅니다. 할 일을 알려 줄 때만 '~하세요'를 씁니다.
2. **버튼·메뉴·제목은 명사형.** 동작을 정확히 이름 짓습니다. 예: 담당 지정, 확인 처리, 초안 작성, 원문 보기
3. **사실만, 짧게.** 덧말("꼭", "몇 분 걸려요", "알려 드릴게요")과 맞장구, 감탄을 쓰지 않습니다.
4. **오류는 무엇이 + 어떻게.** 원인과 해결 방법만 씁니다. 사용자 탓을 하지 않습니다.
5. **장식 금지.** 이모지, 줄표(—), 말줄임표, 굽은 따옴표 강조, 장식 기호 아이콘을 쓰지 않습니다.
6. **용어는 하나로.** 아래 용어집을 따릅니다.

## 용어집
| 쓰는 말 | 쓰지 않는 말 |
| --- | --- |
| 미확인 | 할 일, 받은 공시 |
| 확인 처리 | 확인 완료, 읽음 |
| 담당 지정 / 담당 해제 | 맡기, 내가 쓸게요 |
| 담당 미지정 | 담당 미정, 담당 없음 |
| 내 담당 | 내가 맡은 건 |
| 기사화 기록 | 기사 썼어요 |
| 원문 보기 | 원문 열기 |
| 초안 작성 | 초안 쓰기 |
| 실행 취소 | 되돌리기 |
| 인증키 | 키 |
| 기록 모드 / 알림 발송 | 기록만, 알림 보냄 |
| 당기 / 전기 | 올해 / 작년 (결산표) |

## 바꾼 예
| 이전 | 지금 |
| --- | --- |
| 확인할 중요 공시 3건, 그중 3건은 아직 담당이 없어요. | 미확인 중요 공시 3건 중 3건이 담당 미지정입니다. |
| 지금은 '기록만' 모드예요. 팝업 없이 모으며 알림량을 재고 있어요. | 기록 모드입니다. 공시는 수집하지만 알림은 발송하지 않습니다. |
| 모두 확인했어요 / 새 공시가 오면 여기에 쌓여요. | 미확인 공시가 없습니다 / 새 공시는 수집되는 대로 표시됩니다. |
| 원자료에 없는 숫자 2개 — 꼭 확인하세요. | 원자료에서 확인되지 않은 숫자 2개 |
| 이번 달 AI 사용 한도를 다 썼어요. 관리자에게 한도 조정을 요청해 주세요. | 이번 달 AI 사용 한도를 초과했습니다. 한도 조정은 관리자에게 요청하세요. |

## AI가 만드는 글
- 질문 답변: 합니다체, 결론 먼저, 개조식 허용, 번역투·상투어·굵은 글씨·줄표 금지 (`newsbot/qa.py`)
- 정기 브리핑: 5줄 이내 개조식, 명사형 종결 (`newsbot/qa.py`)
- 기사 초안: 기사체, 번역투('~에 대해', '~를 통해')와 상투어('귀추가 주목된다') 금지 (`newsbot/writing.py`)
